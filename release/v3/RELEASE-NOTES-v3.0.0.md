# SURID Bangladesh GitHub Pages v3.0.0

This release expands the public site into a modern static web application and reusable design system while preserving the safety boundaries required for GitHub Pages.

## Design and interaction

- Animated gradient-mesh backgrounds and ambient visual effects
- Responsive bento layouts, glass panels, cards, badges, alerts and metric widgets
- Light/dark appearance modes and English/Bangla interface controls
- Reading progress, scroll reveal, animated counters and progress bars
- Keyboard-accessible command search with Ctrl/Command + K
- Responsive navigation, mobile controls, filters, tabs and accordions

## Components and assets

- Reusable button, link, form, navigation and feedback components
- SVG icon sprite and branded illustration assets
- UI component reference page
- Downloadable media and asset library page
- Accessible programme, resource and report filters
- Chart widgets with semantic tables and screen-reader descriptions

## Information architecture

The release contains 18 static HTML pages covering the homepage, organization, programmes, impact, stories, partners, reports, media library, component library, governance, FAQ, contact, donation instructions, privacy, safeguarding, accessibility, offline and error states.

## Quality and safety

- Internal links and local assets are validated before deployment
- JavaScript and service-worker syntax are checked in CI
- PWA manifest, service worker, offline fallback, sitemap and robots rules are included
- GitHub Pages does not process payments, issue receipts, confirm donations, run private webhooks or accept safeguarding case reports
- Charts use programme taxonomy and interface-readiness data rather than unverified beneficiary statistics

# SURID Bangladesh GitHub Pages v4.0.0

Package-enhanced static application release for GitHub Pages.

## Added

- 23-page public application with dashboard, map, search, tools and bookmarks workspaces
- Version-pinned progressive integrations for Fuse.js, Chart.js, Leaflet, Swiper, GLightbox, Tippy.js, Motion, Day.js, idb-keyval and QRCode
- Fuzzy site search, content bookmarks, IndexedDB/localStorage persistence and contact-form drafts
- Interactive charts, operational-area map, carousels, media lightbox, tooltips and motion effects
- QR sharing, Web Share and clipboard actions, print controls and PWA install handling
- Network-status feedback, offline support and graceful package fallbacks
- Structured JSON data for search, dashboard widgets and map locations
- Package manifest and reproducible static build helper

## Safety

This static release does not process payments, confirm donations, issue receipts or collect sensitive safeguarding/PSEA reports. Server-backed APIs and protected workflows remain outside GitHub Pages.

## Validation

- 23 HTML pages and local references validated
- Application, package integration and service-worker JavaScript syntax validated
- Deployment archive SHA-256 verified before publication
